# Inline service emojis

The six category names use decorative animated Telegram emoji images. The labels remain readable text, and the images do not alter the accessible names of the category buttons.

Assets are served locally from `public/images/emojis/` as 48px animated WebP files. Each emoji has a static `-still.webp` companion selected by the picture element when `prefers-reduced-motion: reduce` is active.

| Category | Telegram emoji | Source file |
| --- | --- | --- |
| Mobile Legends | Gem Stone | Objects/Gem Stone.webp |
| Account marketplace | Handshake | People/Handshake.webp |
| Boost | Rocket | Travel and Places/Rocket.webp |
| Account rental | Key | Objects/Key.webp |
| Telegram | Glowing Star | Animals and Nature/Glowing Star.webp |
| AI | Robot | Smileys/Robot.webp |

Source collection: https://github.com/Tarikul-Islam-Anik/Telegram-Animated-Emojis

Original emoji artwork belongs to Telegram.org, as credited by the source collection, which obtained the images from Emojipedia. These are animated Telegram emoji illustrations rendered within the Mini App; they do not use Telegram subscription-only custom emoji entities or require a visitor to subscribe to Premium.
